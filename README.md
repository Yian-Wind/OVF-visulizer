# OVF Visualizer

面向 Mumax3 导出 OVF 文件的浏览器端可视化工具。当前版本支持：

- 自动识别温度扫描文件并绘制温度-磁化强度曲线（M-T）
- 自动识别外场/磁滞文件并绘制磁滞回线（M-H）
- 点击曲线数据点查看对应磁矩分布
- 直接在浏览器中读取本地文件，数据不会上传服务器

## 使用

双击打开 ovf_universal_reader.html，或使用任意静态文件服务器提供该目录。选择一组 OVF 文件后，程序会根据文件名中的 T...K、B...、H... 或 m_hyst_... 标记自动分类；也可以在界面中强制选择温度曲线或磁滞回线模式。

## 目录

    ovf_universal_reader.html   当前主程序
    archive/                    历史版本，仅供对照和回溯

历史版本没有从仓库中删除，便于比较功能演进；新的功能应优先修改主程序，并在提交说明中记录行为变化。

## OVF 兼容范围

程序解析 Mumax3 常见 OVF 2.0 文本、Binary 4 和 Binary 8 数据，读取网格尺寸、步长、值倍乘因子和磁矩分量。文件名中的外场单位按程序约定解析为 Oe，并换算为 A/m；使用前请确认仿真的命名和单位约定。

## 开发检查

- 这是无构建步骤的单文件前端项目。
- 修改后至少在 Chromium/Chrome 中打开主程序，加载一组小型文本 OVF，检查曲线、点选查看和错误提示。
- 不要提交真实仿真数据、导出图片、压缩包或浏览器缓存。
